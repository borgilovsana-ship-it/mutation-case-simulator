# Mutation Case Simulator 🌱

A cozy mobile-friendly garden case-opening game prototype.

## Play the game

The game is in `index.html`. To publish it as a free browser game with GitHub Pages:

1. Open this repository on GitHub.
2. Open **Settings**.
3. Open **Pages** in the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**, then press **Save**.
6. Wait a minute or two. GitHub will show the published game URL on the Pages settings screen.

## Prototype features

- Open garden cases for 100 coins
- Six plant types with different rarity levels
- Five mutations; a plant can have multiple mutations at once
- Inventory and sell button
- Daily coin bonus
- Browser-local save data

## Notes

This is an early browser prototype. Progress is stored locally in the browser on the device, so it does not automatically sync between devices. It is not an Android APK yet.
