# Mutation Case Simulator — план разработки

## Цель
Мобильный симулятор открытия кейсов с коллекцией предметов и мутаций. Первая версия должна быть простой, понятной и удобной на Android.

## Первая версия (MVP)
1. Главный экран с балансом монет.
2. Кнопка открытия кейса и цена открытия.
3. Случайная награда с названием, редкостью и стоимостью.
4. Мутации, которые могут выпадать вместе на одном предмете.
5. Инвентарь с полученными предметами.
6. Продажа предмета за монеты.
7. Сохранение баланса и инвентаря на устройстве.

## Стартовые правила (можно менять)
- Стартовый баланс: 500 монет.
- Обычный кейс: 100 монет.
- За открытие игрок получает один случайный предмет.
- У предмета есть базовая цена, редкость и 0–3 возможные мутации.
- Цена продажи рассчитывается из базовой цены и бонусов мутаций.

## Технология
Первую версию собираем в Construct 3, чтобы можно было работать визуально без ручного написания большого объёма кода. GitHub используем для хранения документации и файлов проекта.
